A CqLevelEntityLayer is a layer containing all interactive entities of a level, e.g. the Cookie Monster, the enemies, jumping coils/barrels etc..

Instance Variables
	cookieMonster:		<CqCookieMonster>
	metadata:		<CqLevelMetadata>

cookieMonster
	- the entity controlled by the player

metadata
	- the metadata of the level, containing e.g. the tile and level size and the file paths to the tile images
