A CqHeadUpDisplay is used to display some infos about the score.

Instance Variables
	cookieNumber:		<Integer>
	cookiePicture:		<ImageMorph>
	lifeNumber:		<Integer>
	lifePicture:		<ImageMorph>

cookieNumber
	- number of collected cookies

cookiePicture
	- picture to display a cookie

lifeNumber
	- number of remaining live

lifePicture
	- picture to display a life
