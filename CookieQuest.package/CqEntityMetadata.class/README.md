A CqEntityMetadata contains metadata informations used to construct entities based on a STON-levelfile.

Instance Variables
	position:		<Point>
	properties:		<Symbol>
	size:		<Point>
	type:		<String>

position
	- top left position of constructed entity

properties
	- property symbol of constructed entity

size
	- extent of the constructed entity

type
	- name of the constructed class (without prefix)
