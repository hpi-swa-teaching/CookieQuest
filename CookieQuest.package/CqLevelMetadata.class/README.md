A CqLevelMetadata object contains the metadata of the level, e.g. the tile and level size and the file paths to the tile images.

Instance Variables
	cookieMonsterSpawn:		<Object>
	gravity:		<Object>
	tileHeight:		<Object>
	tileQuantityHorizontal:		<Object>
	tileQuantityVertical:		<Object>
	tileWidth:		<Object>
	tiles:		<Object>

cookieMonsterSpawn
	- the position of the Cookie Monster in the beginning

gravity
	- the gravity of the level

tileHeight
	- the height of a single tile

tileQuantityHorizontal
	- the number of tiles horizontally

tileQuantityVertical
	- the number of tiles vertically

tileWidth
	- the width of a single tile

tiles
	- a collection of CqTileMetadata objects, describing the tiles used within the level
