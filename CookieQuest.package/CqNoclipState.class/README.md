A CqNoclipState is a debug mode. The stateholder will not be influenced by collisions and gravity.

Instance Variables
	savedCollisionStrategies:		<Object>
	savedGravityInfluence:		<Object>

savedCollisionStrategies
	- the collision strategies of the stateholder before entering no-clip

savedGravityInfluence
	- the gravity influence of the stateholder before entering no-clip
