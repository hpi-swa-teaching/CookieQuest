A CqCookieMonster is the hero in this game and is controlled by the player.

Instance Variables
	alive:		<Boolean>
	cookieQuantity:		<Integer>
	levelLoadingBlocks:		<CqLevelLoadingBlocks>
	lifeQuantity:		<Integer>

alive
	- flag whether the cookiemonster is alive

cookieQuantity
	- number of cookies collected by the cookiemonster

levelLoadingBlocks
	- encapsulated functionality of CqWorld

lifeQuantity
	- number of remaining live
