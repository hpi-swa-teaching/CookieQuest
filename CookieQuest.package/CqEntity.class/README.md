A CqEntity is an entity that can be collided with..

Instance Variables
	collisionStrategies:		<IdentityDictionary>
	jumpiness:		<Integer>
	jumpinessFactor:		<Integer>
	level:		<CqLevel>

collisionStrategies
	- maps a entiy property to a CollisionStrategie

jumpiness
	- value how high an entity can jump

jumpinessFactor
	- factor multiplied with jumpiness

level
	- level in which the entity is placed
