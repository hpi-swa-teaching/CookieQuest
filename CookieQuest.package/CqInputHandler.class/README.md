A CqInputHandler maps input to actions.

Instance Variables
	keyDownActions:		<IdentityDictionary>
	keyStrokeActions:		<IdentityDictionary>
	keyUpActions:		<IdentityDictionary>
	pressedKeys:		<IdentitySet>

keyDownActions
	- mapping of keyDownEvents

keyStrokeActions
	- mapping of keyStrokeEvents

keyUpActions
	- mapping of keyUpEvents

pressedKeys
	- keys that are currenty pressed
